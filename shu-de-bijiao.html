基本法则：数轴就是"大小秤"

先认清数的大小"地形"

四条基本法则

① 数轴法则数轴上的数，越往右越大。正数 > 0 > 负数。
② 两个负数比大小绝对值大的反而小。例如 −5 和 −3：|−5|=5 > 3=|−3|，所以 −5 < −3。（负得越多，离 0 越远，位置越靠左）
③ 正数 vs 负数正数 永远大于负数，不用算。
④ 字母题为什么难？a、b 的正负不确定时，法则用不上——这时就要请出四大方法。

实验：拖动 a，看 a、−a、|a| 谁大谁小

注意观察 a 穿过原点的一瞬间，−a 的位置"跳"到哪边去了：

👆 拖动蓝色点 a，粉色点 −a、绿色点 |a| 会跟着动
🚫 经典坑：−a 一定是负数吗？ 拖到 a=−2 试试：−a = 2，是正数！当 a<0 时，−a > a（和直觉相反）。这就是字母题必须用方法的原因——别用"感觉"比大小。

方法一：特殊值法

选择题神器：把字母换成数，答案立刻现形

什么时候用？

题目里全是字母（a、b、x……），又给了范围或条件，让你比较大小或排序——而且是选择、填空题。做法：在范围内取一个好算的数，代进去算出每个式子的值，直接排。

⚠️ 三条军规 1）取值必须在题目范围内；2）选好算的数（整数优先，避开 0、±1 边界）；3）只适用于选择填空——解答题用特殊值会被扣分（不能代替证明）！

例题：若 0 < a < 1，比较 a、a²、1/a 的大小

取特殊值 a = 0.5，点按钮看三个数算出来怎么排队：

✅ 结论 a² = 0.25 < a = 0.5 < 1/a = 2，即 a² < a < 1/a。
🧠 记住这个模型：0 到 1 之间的数，平方变小、倒数变大（越乘越"缩水"，除以小数反而变大）。
【特殊值法书写示范】
解：取 a = 1/2（在 0 < a < 1 范围内），
　则 a² = (1/2)² = 1/4，1/a = 1÷(1/2) = 2，
　∵ 1/4 < 1/2 < 2，∴ a² < a < 1/a。

方法二：测试点法

范围分几段，就取几个点试

什么时候用？

题目给了取值范围或分段条件（如数轴上 a、b 的位置已知，或 |a|>|b| 这类条件），在每一段里取一个代表数代入验证。和专题 1 的"各段定号"是同一个思想。

实验：已知 −1 < a < 0 < 1 < b，比较 a、b、−a、−b、a+b

拖动 a（只能在 −1 和 0 之间）和 b（在 1 右边），看五个数在数轴上的实时排位：

👆 蓝点 = a（负区间），紫点 = b（正区间），都可拖动
✅ 结论（取测试点 a=−0.5，b=2 验证） −b = −2 < a = −0.5 < −a = 0.5 < b = 2；而 a+b = 1.5，介于 −a 与 b 之间。
∴ 排序：−b < a < −a < a+b < b。
📌 方法要点 范围涉及几段，就在每段各取一个好算的测试点（如 a=−1/2、b=2）；排序结论在整段范围内保持不变（只要条件不变号）。

方法三：作差法

a − b 的正负定胜负（解答题首选，最严谨）
a − b > 0 ⇔ a > b；　a − b = 0 ⇔ a = b；　a − b < 0 ⇔ a < b

什么时候用？

万能方法，尤其适合解答题（要写过程证明）。作差后关键是判断差的正负——常用配方法或因式分解。

例题：比较 x²+4 与 4x 的大小

解：作差：(x²+4) − 4x
　= x² − 4x + 4
　= (x−2)²　（配成完全平方！）
　∵ 任何数的平方都 ≥ 0，∴ (x−2)² ≥ 0，
　∴ x²+4 ≥ 4x，当 x=2 时等号成立。

实验：拖动 x，看差值 (x²+4) − 4x 何时为 0

👆 拖动蓝点 x，紫色曲线是差值 (x²+4)−4x=(x−2)²——永远不低于 0，只在 x=2 时碰到 0
🌟 判号三件套 作差之后：① 配方成完全平方（≥0）；② 因式分解看每个因子正负；③ 实在不行就分类讨论（回到专题 1 的思想）。

方法四：作商法

两个正数比大小，看商比 1 大还是小
当 a、b 都是正数时：a/b > 1 ⇔ a > b；a/b = 1 ⇔ a = b；a/b < 1 ⇔ a < b

什么时候用？

两个数都是正数、而且带乘法、幂、分数（如 2³⁰ 与 3²⁰）时，作商能约分化简，比作差好算。

🚫 致命前提：必须同号（正数）！ 两个负数作商，结论正好反过来（比如 −6 与 −3：商=2>1，但 −6<−3）。一正一负不能用作商法。不确定正负时，老实用作差法。

例题：比较 2³⁰ 与 3²⁰ 的大小

解：两数都是正数，作商：
　2³⁰ / 3²⁰ = 2⁽²⁰⁺¹⁰⁾ / 3²⁰ = 2¹⁰ × (2/3)²⁰
　= 1024 × (2/3)²⁰，
　更聪明的算法：2³⁰ = (2³)¹⁰ = 8¹⁰，3²⁰ = (3²)¹⁰ = 9¹⁰，
　作商 8¹⁰/9¹⁰ = (8/9)¹⁰ < 1，
　∴ 2³⁰ < 3²⁰。

互动：比较 a 与 b（保证正数），拖动看商 a/b 的变化

👆 拖动 b（a 固定为 6），看商 a/b 落在 1 的哪一侧：商 > 1 则 a > b

选方法口诀 + 错题医院

对症下"药"

四把钥匙怎么选？

①

特殊值法：选择填空、字母给范围 → 代个好算数，秒排

②

测试点法：条件分段 / 数轴位置已知 → 每段取一点

③

作差法：解答题证明、万能 → 作差判正负（配方/因式分解）

④

作商法：两数都是正数、带乘幂分数 → 作商比 1（负数反号！）

🏥 错题医院：点击你认为写错的地方

病历 1　比较 −7 和 −4 的大小
解：∵ |−7| = 7 > 4 = |−4|，
∴ −7 > −4。
诊断：两个负数比大小，绝对值大的反而小！−7 在数轴上更靠左。正确：−7 < −4。
病历 2　比较 a 与 −a（解答题）
解：取 a = 2，则 −a = −2，
∴ a > −a（证明完毕）。
诊断：两个问题：① 特殊值不能用于解答题证明，只能选择填空用；② 结论还不全面：a>0 时 a>−a；a=0 时 a=−a；a<0 时 a<−a（如 a=−2，−a=2）。必须分类讨论或用作差法：a−(−a)=2a，看 2a 的正负分三类。
病历 3　比较 a=−6 与 b=−3（用作商法）
解：a/b = (−6)/(−3) = 2 > 1，
∴ a > b，即 −6 > −3。
诊断：作商法"商大于 1 则被除数大"的规则只对两个正数成立！两个负数作商，结论要反过来看：商 2>1 反而说明 |a|>|b|，即 a 更小。正确：−6 < −3。负数比大小建议直接用"绝对值大的反而小"或作差法：−6−(−3)=−3<0。

🎓 一页纸总结

  1. 基本法则：数轴向右增大；两个负数，绝对值大的反而小；正数恒大于负数。
  2. 特殊值法：选择填空 + 字母给范围 → 代好算数，不能用于证明题。
  3. 测试点法：范围分几段，每段取一个代表点，结论整段不变。
  4. 作差法：a−b 看正负，万能、适合解答题；判号靠配方、因式分解。
  5. 作商法：仅限两个正数，商比 1 定大小；负数结论反号，一正一负不能用。
