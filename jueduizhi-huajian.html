为什么非要"讨论"？

先拖一拖这个点

实验：拖动点 a，观察 |a| 等于什么

在数轴上左右拖动蓝色圆点，让它经过原点，仔细看下方的判定结果：

👆 按住圆点左右拖动（手机上直接滑动圆点）
💡 你发现了吗？ 同一个符号 |　|，背后藏着三个不同的公式：点在右边用一个、点在左边用另一个、原点上又是一个。到底用哪个，取决于绝对值里面的数是正还是负。
📌 什么是"分类讨论"思想？ 当题目里字母的正负（或大小关系）不确定时，我们没办法用一句话回答，就把所有可能的情况分成几类，一类一类研究清楚，最后汇总成结论。分类的铁律是四个字：不重不漏——类与类之间不重叠，合起来覆盖所有情况。
📏 顺便记住几何意义 |a| 是数轴上点 a 到原点的距离；|a−b| 是点 a 与点 b 两点之间的距离。距离永远是非负的——这就是绝对值"非负性"的来历。

三句话定义，一张 V 形图

|a| 的完整真面目

绝对值的三句话

a 是正数
|a| = a
正数的绝对值是它本身
a 是 0
|a| = 0
0 的绝对值是 0
a 是负数
|a| = −a
负数的绝对值是它的相反数

实验：函数图像 y = |x| 是个"V"字

拖动数轴上的 x，图像上的点跟着走。注意看：右半边是蓝线（y=x），左半边是粉线（y=−x），在原点处折了一下——这个"折点"就是后面要找的零点。

👆 拖动蓝色圆点，观察折点两侧颜色不同
⚠️ 最容易误会的一点 "−a" 不一定是负数！当 a 本身是负数时，−a 反而是正数（比如 a=−3 时 −a=3）。字母前面有负号 ≠ 这个数是负数，判断正负永远要看条件。

零点分段法：五步法 + 规范书写

以化简 |x−2| 为例（核心方法）

跟着五步走，每步点一下按钮

第④步：请拖动数轴上的测试点，分别到零点左右两侧试一试
解：令 x−2 = 0，得 x = 2。   ① 当 x ≥ 2 时，x−2 ≥ 0， 　　∴ |x−2| = x−2；   ② 当 x < 2 时，x−2 < 0， 　　∴ |x−2| = −(x−2) = 2−x。
|x−2| = ⎧ x−2 （x ≥ 2） 2−x （x < 2）

🏆 进一步想最小值：x≥2 段递增（起点 x=2 值为 0）、x<2 段递减（y>0 取不到 0）→ 整个 |x−2| 的最小值 = 0，在 x=2（零点！）时取到。单个绝对值的最小值永远是 0，在内部等于 0 时取到。

🚫 红笔提醒 1：括号！括号！括号！ 负数去绝对值时，要把整个内部套上括号再取相反：−(x−2)，负号分配进去是 −x+2 = 2−x。直接写成 −x−2 是最高频错误——负号只光顾了 x，漏掉了 −2 变号。
🚫 红笔提醒 2：等号"="挂在哪边？ 零点 x=2 这一类，可以单独写，也可以挂进相邻一段（写成 x≥2 或 x≤2 都行），但绝不能两段都带等号（重叠），也不能两段都不带（遗漏）。这就是"不重不漏"在书写上的体现。

多个绝对值：零点排序，分三段

以化简 |x+1|+|x−2| 为例

两个零点 = 两道"闸门"，分出三个房间

令每个绝对值内部等于 0：x+1=0 → x=−1；x−2=0 → x=2。把零点从小到大排好，数轴被分成三段。拖动测试点 x 到三个"房间"里，看每个绝对值内部怎么变号：

👆 拖动圆点，分别进入粉色（左）、黄色（中）、蓝色（右）三个区间
分段化简结果 + 每段最小值讨论：
x 的范围x+1x−2|x+1|+|x−2| =这段的最小值是多少？
x < −1负负−(x+1)−(x−2) = −2x+1 📉 系数 −2<0，递减：越往右（靠近 x=−1）越小
但 x<−1 取不到 −1，只能无限接近
∴ y > 3，这段没有最小值（下界 3，达不到）
−1 ≤ x ≤ 2正 / 零负(x+1)−(x−2) = 3 ➡️ 恒等于 3（常数）
端点 −1、2 都属于本段（≤）
∴ 最小值 = 3，整段都能取到 ✅
x > 2正正(x+1)+(x−2) = 2x−1 📈 系数 2>0，递增：越往左（靠近 x=2）越小
但 x>2 取不到 2，只能无限接近
∴ y > 3，这段没有最小值（下界 3，达不到）
三段放一起比较 → 全局最小值 🏆 最小值 = 3
当 −1 ≤ x ≤ 2 时取到
🔍 每段最小值怎么求？——一次函数「三看」 一看式子：每段化简结果都是 y = kx + b（一次函数或常数）；
二看系数 k：k > 0 → 递增，最小值在左端点；k < 0 → 递减，最小值在右端点；k = 0 → 常数，整段都是最小值；
三看端点能不能取到：端点写 ≤ / ≥（闭区间）→ 能取到，写"最小值 = …"；端点写 < / >（开区间）→ 只能无限接近，写"y > …"，这段没有最小值；
最后把各段的最小值放在一起比较，最小的那个就是全局最小值。

规范书写：求 |x+1|+|x−2| 的最小值

解：令 x+1=0 得 x=−1；令 x−2=0 得 x=2。分三段讨论： ① 当 x < −1 时，原式 = −2x+1。 　∵ 系数 −2 < 0，原式随 x 增大而减小， 　∴ 原式 > −2×(−1)+1 = 3（x=−1 不在本段，取不到）； ② 当 −1 ≤ x ≤ 2 时，原式 = 3， 　∴ 本段最小值为 3，整段都能取到； ③ 当 x > 2 时，原式 = 2x−1。 　∵ 系数 2 > 0，原式随 x 增大而增大， 　∴ 原式 > 2×2−1 = 3（x=2 不在本段，取不到）。 三段比较，3 最小。 ∴ 原式的最小值为 3，当 −1 ≤ x ≤ 2 时取到。
🌟 几何意义彩蛋（华育常考：最小值问题） |x+1| 是 x 到 −1 的距离，|x−2| 是 x 到 2 的距离。当 x 落在 −1 和 2 之间时，两段距离拼起来正好等于 −1 到 2 的距离 = 3——这就是图像上那段黄色"平底"（绿色端点之间）！所以 |x+1|+|x−2| 的最小值是 3，在 −1≤x≤2 时取到。分段计算、画图、想距离，三种方法殊途同归。

带取值范围的化简题

考试压轴题型：范围帮你"过滤"零点

例题：已知 −2 < x < 3，化简 |x+2| − |x−3| + |x|

关键动作：先找全零点，再用范围"过滤"。三个零点是 x=−2、x=0、x=3。看数轴：黄色亮带是题目给的范围 −2<x<3——落在范围内部的零点（红色牌 x=0）必须分段讨论；压在边界上的零点（灰色牌 x=−2、x=3）范围一开就被排除，不用分段。

👆 拖动圆点在黄色范围内移动，跨过内部零点 x=0，观察分段变化
✅ 所以真正要讨论的只有两段： 段① −2<x<0：x+2>0，x−3<0，x<0
　　原式 = (x+2) −〔−(x−3)〕+ (−x) = x+2+x−3−x = x−1
段② 0≤x<3：x+2>0，x−3<0，x≥0
　　原式 = (x+2) −〔−(x−3)〕+ x = x+2+x−3+x = 3x−1
🔍 做完要检验（代个数试试） 段①取 x=−1：|1|−|−4|+|−1| = 1−4+1 = −2，公式 x−1 = −2 ✓；段②取 x=1：|3|−|−2|+|1| = 3−2+1 = 2，公式 3x−1 = 2 ✓。
📋 范围题三步走 1️⃣ 找全所有零点（令每个绝对值内部 = 0）→ 2️⃣ 用范围过滤：只有落在范围内部的零点才分段，边界零点靠不等号带上等号 → 3️⃣ 逐段定号、去符号、合并，最后代个检验数。

🏥 错题医院：点击你认为写错的地方

下面三份"病历"都来自真实作业。点击红色波浪线标出的错误位置，查看诊断：

病历 1　化简 |x−2|（x < 2 时）
解：当 x < 2 时，x−2 < 0，
∴ |x−2| = −x−2。
诊断：负数去绝对值，要把整个内部套括号取相反：−(x−2)，负号分配进去是 −x+2 = 2−x。写成 −x−2 等于只给 x 变了号，把 −2 漏掉了——括号就是来防止这种事故的。
病历 2　化简 |x+1| + |x−2|
解：分两类：当 x > 0 时……；当 x < 0 时……
诊断：零点不是凭感觉找的 0！必须令每个绝对值内部等于 0：x+1=0 得 x=−1，x−2=0 得 x=2。正确分界点是 −1 和 2，数轴被分成三段。记住：零点 = 解方程解出来的，不是看出来的。
病历 3　化简 |x−2| 的分段结论
① 当 x ≥ 2 时，|x−2| = x−2；
② 当 x > 2 时，|x−2| = x−2；
③ 当 x < 2 时，|x−2| = 2−x。
诊断：x=2 在第①类和第②类里重复出现了，分类重叠，违反"不重不漏"。等号只能挂在一边：要么 ①x≥2 / ③x<2，要么 ①x>2 / ②x=2 单独写 / ③x<2。

🎓 一页纸总结

  1. 为什么讨论：绝对值里面的正负不确定时，|　| 对应多个公式——条件不确定，就分类讨论，原则是不重不漏。
  2. 怎么找分界：令绝对值内部 = 0，解出零点；多个零点就排序，零点把数轴分成 n+1 段。
  3. 每段怎么做：取测试点定号 → 正数照抄、负数整体加括号取相反 → 合并化简。
  4. 带范围的题：先过滤零点，只有范围内部的零点才需要分段，边界零点交给不等号。
  5. 终极武器：|x−a| 是距离。几个距离之和的最小值，看图像的"平底"或想点的位置，压轴题常这样秒杀。
